# BMI・体重変化可視化アプリ 要件定義書

## 文書情報

| 項目 | 内容 |
| --- | --- |
| ステータス | 初期版の基本要件確定 |
| 作成日 | 2026-10-03 |
| 対象 | BMIと体重の変化を可視化するWebアプリ |

本書では、初期版の決定済み要件と対象外の機能を記載する。R-01以降には要件を具体化する際に追加で確認した決定内容を記録する。

## 1. 目的と背景

体重の推移、目標体重との差、およびBMIに基づく評価を、時系列グラフを中心に把握できるアプリを作成する。データはリポジトリ内のCSVファイルから読み込む。

## 2. 現時点で決まっていること

- アプリで体重とBMIの変化を可視化する。
- データの入力元は、リポジトリ内に置くCSVファイルとする。
- 表示対象には、体重の変化、目標体重との差分、BMI観点での評価を含める。
- BMIの標準範囲をグラフ上に表現する。
- 詳細な決定内容は「11. 決定済み事項」を参照する。

## 3. リポジトリの現状

- 現在のアプリはNext.jsのサンプル画面とSQLiteを使ったメッセージ表示を中心としており、BMI記録の機能はまだない。
- 現在、リポジトリ内にBMI・体重データ用のCSVは確認できない。
- `.gitignore` では `/data/` が除外されている。匿名サンプルCSVをGit管理する際は、サンプルファイルだけ除外対象から外し、実データは引き続きGit管理対象外とする。

この節は実装開始時に現状と差がないか再確認する。

## 4. 対象範囲

### 4.1 対象とする機能

1. リポジトリ内のCSVを読み込んで記録データを取得する。
2. 日付に沿った体重の推移をグラフで表示する。
3. 目標体重と実測体重との差を数値で確認できるようにする。
4. 各記録のBMIを算出し、BMIに基づく評価を表示する。
5. BMI標準範囲の帯と目標体重の基準線をグラフ上に表示する。

### 4.2 初期版の対象外とする機能

画面からのCSVアップロード・データ入力、複数ユーザー、認証、通知、データの外部連携、エクスポートなどは、必要性を確認するまで要件に含めない。CSVファイルを直接編集・差し替える運用は対象とする。

## 5. 用語と計算ルール

| 用語 | 定義 | 適用ルール |
| --- | --- | --- |
| BMI | 体重(kg) ÷ 身長(m)² | 身長はプロフィール設定に登録。表示は小数第1位。BMI区分は成人向け基準 |
| 目標体重との差分 | 実測体重 − 目標体重。正なら目標より重く、負なら軽い | kg単位、小数第1位で表示 |
| BMI標準範囲 | BMI 18.5以上25未満に対応する体重の範囲 | 身長から体重に換算し、体重グラフ上の帯として表示 |

BMIの評価は健康状態の診断を行うものではない旨を画面に表示する。

## 6. 機能要件

| ID | 要件 | 条件 |
| --- | --- | --- |
| FR-01 | アプリは `data/` のCSVを読み込み、ページ表示ごとに最新ファイル内容を反映する。 | 初期版は匿名サンプルCSVのみを使用 |
| FR-02 | アプリは日付順の体重推移をグラフ表示し、点を選ぶと該当記録を確認できるようにする。 | 全期間を初期表示し、今日から遡る移動期間で1か月・3か月・6か月へ切替可能。選択点に日付・体重・BMIを表示 |
| FR-03 | アプリは現在の目標体重を基準に、実測体重との差分を確認できるようにする。 | 「実測 − 目標」、kg、小数第1位。目標変更前の値は保持しない |
| FR-04 | アプリはプロフィールCSVの身長と測定CSVの体重からBMIを算出し、成人向け区分を表示する。 | BMI区分・プロフィールCSV形式・身長と目標体重の許容範囲は決定 |
| FR-05 | 体重グラフにBMI標準範囲の帯と目標体重の基準線を表示する。 | 表示方法および採用基準は決定 |
| FR-06 | CSVを読み込めない場合や有効な記録がない場合、利用者が状態を把握できるようにする。 | 不正データはファイル上の行番号と理由を示して全体エラー。ヘッダーのみのCSVは「記録がありません」と表示 |

## 7. データ要件

### 7.1 CSVの項目

測定CSVはUTF-8、カンマ区切り、ヘッダー付きとする。列名は `date,weight_kg`、日付は `YYYY-MM-DD`。身長と目標体重は測定CSVに含めない。

| 項目 | 用途 | 要件 |
| --- | --- | --- |
| `date` | 時系列グラフの横軸 | 必須。`YYYY-MM-DD` |
| `weight_kg` | 推移グラフとBMI算出 | 必須。1 kg以上999 kg以下。kg単位。読込時に小数第1位へ四捨五入し、丸めた値を表示・計算に使う |
| `height_cm` | BMI算出 | プロフィールCSVにcm単位、小数第1位まで1つ登録。0より大きく300 cm以下。登録値を丸めずBMI計算に使用 |
| `target_weight_kg` | 実測体重との差分 | プロフィールCSVにkg単位・0.1 kg刻みで現在値を1つ登録。1 kg以上999 kg以下。登録値を丸めず差分計算に使用 |

### 7.2 CSVの運用方針

- 匿名サンプルは `data/weight-sample.csv` と `data/profile-sample.csv` としGit管理する。実データ用 `data/weight.csv` と `data/profile.csv` はGit管理しない。
- CSVはページ表示ごとに読み直す。初期版では匿名サンプルのみを使い、実データ利用は対象外とする。
- 欠損値、同じ測定日の複数記録、JSTでの未来日付、不正値のいずれかがあればCSV全体をエラーとし、部分表示しない。CSV内の並び順は問わず、表示時に日付順に並べる。

## 8. 画面・グラフ要件

次の表現を要件とする。

- 横軸に日付、縦軸に体重をとり、測定値の推移を表示する。
- 初期表示は全期間とし、JSTの今日から遡る移動期間として1か月・3か月・6か月に切替可能にする。
- 目標体重を基準線として表示し、差分は「実測 − 目標」をkg単位、小数第1位で示す。
- 成人向けBMI区分（18.5未満、18.5以上25未満、25以上）を用いる。表示は診断ではない旨を明記する。
- BMI標準範囲の上下限を身長から体重に換算して帯で示し、目標体重の線も同じグラフに表示する。
- グラフ上の点を選択すると、その記録の日付・体重・BMIを表示する。
- ページ上部に最新記録と目標体重との差をまとめて表示する。

## 9. 非機能・運用上の検討事項

- **個人情報:** 体重・身長は個人に関する情報である。実データをGitに含めず、Git管理するのは匿名サンプルCSVに限る。
- **データ更新:** CSVはページ表示ごとに読み直す。初期版では匿名サンプルのみを使い、実データをVercel等のデプロイ環境に配置しない。
- **対象環境:** PC・スマートフォンの両方を対象とし、Chrome・Edge・Safari・Firefoxの最新安定版をサポートする。
- **アクセシビリティ:** WCAG 2.2 AA相当を目標とする。キーボード操作、色コントラスト、グラフ内容のテキスト代替を初期版の必須要件とする。
- **性能:** 体重記録1,000件までを初期目標とし、CSV読込・グラフ表示を行う。

## 10. 受け入れ条件

1. `date,weight_kg` 形式の有効なCSVを読み込み、日付順の体重推移を全期間および選択した期間で確認できる。
2. 現在の目標体重との差を、実測体重から目標体重を引いたkg単位・小数第1位で確認できる。
3. プロフィールの身長と測定体重からBMIを算出し、成人向けBMI区分を確認できる。
4. BMI標準範囲が身長に整合した体重グラフ上の帯として表示され、目標体重が基準線として表示される。
5. CSVに欠損・同日重複・JSTでの未来日付・不正な行がある場合、全体を読み込まず、問題箇所を案内する。入力順が異なっていても日付順に表示する。ヘッダーのみで記録行がない場合は空グラフと「記録がありません」を表示する。
6. PC・スマートフォンの両方で主要なグラフと数値を確認できる。
7. グラフ上で記録点を選択し、その日付・体重・BMIを確認できる。最新記録と目標との差も確認できる。
8. すべての操作をキーボードで行え、WCAG 2.2 AA相当の色コントラストを確保し、グラフの情報をテキストでも確認できる。
9. 体重記録1,000件までを読み込み、グラフ表示できる。

## 11. 決定済み事項

| ID | 質問 | 決定内容 |
| --- | --- | --- |
| Q-01 | このアプリを使うのは本人一人ですか、それとも複数人の記録を扱いますか。 | 本人一人分を扱う |
| Q-02 | CSVはどのディレクトリに置きますか。また、Gitで管理するCSVに実際の測定データを含めますか。 | `data/` に置く。匿名サンプルCSVのみGit管理し、実測データはGit管理しない |
| Q-03 | CSVの列名・日付形式・文字コード・区切り文字をどうしますか。 | ヘッダー付き `date,weight_kg`、日付 `YYYY-MM-DD`、UTF-8、カンマ区切り |
| Q-04 | 身長はどこから取得しますか。一定値として設定しますか、それとも記録ごとにCSVへ含めますか。 | プロフィール設定に一度登録し、測定CSVには含めない |
| Q-05 | 目標体重は一つの固定値ですか、期間や日付ごとに変更する値ですか。どこで管理しますか。 | 現在の目標を一つ設定する。変更時は値を更新し、変更前の値は保持しない |
| Q-06 | 採用するBMI標準範囲と評価区分、境界値の扱いをどうしますか。 | 成人向けに18.5未満＝低体重、18.5以上25未満＝標準範囲、25以上＝高BMI。診断ではない旨を表示する |
| Q-07 | 目標体重との差分は「実測 − 目標」の符号で表示してよいですか。表示単位・小数桁はどうしますか。 | 実測体重 − 目標体重、kg単位、小数第1位 |
| Q-08 | BMIの標準範囲は体重グラフ上の帯として表示しますか、それともBMIの別グラフ・別欄にしますか。 | 身長から換算した標準範囲の帯と目標体重線を体重グラフに表示する |
| Q-09 | グラフの初期表示期間、期間切替、最新記録の選び方をどうしますか。 | 全期間を初期表示し、1か月・3か月・6か月にも切替可能 |
| Q-10 | CSVに欠損・重複・不正な行がある場合、全体をエラーにしますか、有効な行のみ表示しますか。 | CSV全体をエラーにし、問題の行と原因を案内する。部分表示はしない |
| Q-11 | CSVの更新はどの頻度で行い、アプリには再デプロイ時・ページ表示時などいつ反映させますか。 | ページ表示ごとにCSVを読み直す。初期版は匿名サンプルCSVのみを利用する |
| Q-12 | 初期リリースで、CSV編集・アップロード、記録の手動入力、エクスポートは必要ですか。 | 初期版では画面入力・アップロードを設けず、CSVファイル差し替えで更新する |
| Q-13 | PC・スマートフォンのどちらを主な利用環境とし、必要なアクセシビリティ対応はありますか。 | PC・スマートフォンの両方に対応する |
